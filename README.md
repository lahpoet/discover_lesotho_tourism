# Discover Lesotho Tourism Website

A responsive, multi-page tourism website project using HTML5, custom CSS, Bootstrap 5 and JavaScript.

## Pages
- `index.html` — home page and featured highlights
- `about.html` — introduction to Lesotho, culture and responsible travel
- `destinations.html` — searchable and filterable destination cards with a Bootstrap details modal
- `accommodation.html` — accommodation types and activity ideas
- `gallery.html` — image grid with modal preview and previous/next controls
- `contact.html` — contact form, booking enquiry form and estimated trip calculator

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Bootstrap and the sample photographs use external URLs, so an internet connection is needed for those resources.

## Host on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important notes
- Forms are front-end demonstrations only. They validate fields and display a confirmation message, but they do not send email or create a real reservation. A backend or form service would be needed for real submissions.
- The calculator uses sample prices for demonstration, not current provider prices.
- Several photographs are external illustrative landscape images. Check image licensing and replace images/captions with accurate, locally sourced Lesotho images before final submission.
- This is a learning project. Review the code and be prepared to explain how the pages, styles and JavaScript work.
